# USD Impact Site Bootstrap

Session 16A repository bootstrap for `usd-impact.com`.

This package is a GitHub-ready Astro scaffold. It imports the Session 14B product/funnel content and preserves the certified release hierarchy:

- Book baseline: `Session15A_Certified_NoISBN`
- Cover baseline: `Session14APlus_Publisher_Ready_Packaging_Upgrade`
- Website/Astro baseline: `Session14B_Website_Product_Page_Lead_Magnet_System`
- Release-system certification baseline: `Session15B_Full_Release_System_Certification`

## What this repo contains

- Astro project under `apps/web`
- Content collections for pages, products, frameworks, lead magnets, benchmark modules, and glossary terms
- Public assets copied from Session 14B
- Compliance-safe CTA and educational language
- GitHub workflow templates for CI/content audit/deploy placeholder
- No secrets, no API keys, no raw book production archives

## Quick start

```bash
cd apps/web
npm install
npm run dev
npm run build
npm run preview
```

Astro must be installed locally through project dependencies, not globally.

## Release rule

Do not modify the certified Session 15A book files inside this repo. This repository is for the public website and deployment layer.
