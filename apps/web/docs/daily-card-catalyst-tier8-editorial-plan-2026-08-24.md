## Publication boundary

All four generated records remain:

- `status: review`;
- `lastReviewed: null`;
- source hierarchy rank 8;
- exact Catalyst Brief source path attached;
- event key, phase, source review date and publisher provenance attached;
- suggested Open access only because the underlying Catalyst Brief is public.

No canonical Daily Card is added by this change.

## Excluded from evergreen candidate prose

The contract rejects event-specific material such as:

- calendar dates and release times;
- percentage values;
- directional surprise scenarios;
- realized market moves or outcomes;
- trading recommendations.
