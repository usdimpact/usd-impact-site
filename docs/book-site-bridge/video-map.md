2. identify the corresponding HeyGen source run, if retained;
3. verify title, duration, captions, transcript, visual QA and compliance ending;
4. mark superseded duplicate runs as non-canonical in the registry without deleting them;
5. add chapter and tool IDs to the approved asset record;
6. link only the canonical hosted asset from the companion.

## New-render gate

A new video is justified only when the approved inventory lacks a necessary explanation that cannot be handled more effectively by text, diagrams or the interactive practice. Any later render requires a separately approved script and scene plan, English voice-over only, no visible avatar by default, captions, transcript, a relevant practice link and no sales ending.
