## Identity rule

A WAV becomes acceptable for final technical mastering QA only when all of the following are recorded:

1. exact selected composition ID matches this ledger;
2. file is WAV/lossless;
3. export provenance or equivalent direct identity evidence ties the file to that exact composition;
4. sample rate, bit depth and channel count are measured from the file, not assumed;
5. SHA-256 is recorded from the exported bytes;
6. decoded duration is reconciled against the expected selected-composition duration, with sample/container rounding noted;
7. no alternate candidate is silently substituted.

Do not publish or upload to member storage. Keep files private, then run decoder integrity, LUFS, true peak, clipping, excessive-silence, seam, and cross-track balance measurements. Final mastering approval and legal/publisher distribution approval remain separate.
