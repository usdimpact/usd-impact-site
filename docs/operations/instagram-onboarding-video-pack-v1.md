# HOW-001 — Start Here: How to Use USD Impact

## Goal

Explain the platform's intended learning and research flow in one minute.

## Verified product path

The account learning journey currently uses this sequence:

1. Guided Edition as the default starting point.
2. Audiobook and Video Library as reinforcement.
3. Weekly Checklist / current research as the recurring application layer.
4. Account recommendations use existing learning progress and fall back safely to Guided Edition when progress is unavailable.

## Target duration

45–55 seconds.

## Narration

> If you are new to USD Impact, do not try to use everything at once. Start with the Guided Edition to learn the framework. Then reinforce the same ideas with the audiobook or the Video Library. When you return to the platform, use your account page to continue from the recommended next step. For current markets, check Daily USD Impact for verified developments, then use Weekly Score and the Weekly Checklist to place those developments inside a broader regime. Reports are for deeper themes. Learn the method first, then use the current research to practice it. That is the simplest way to use USD Impact.

## Scene map

1. Branded opener: `HOW TO USE USD IMPACT`
2. Start Here / Guided Edition card
3. Library reinforcement: Audiobook + Video Library
4. Account / recommended next step
5. Daily USD Impact
6. Weekly Score + Weekly Checklist
7. Reports
8. End frame: `LEARN → REINFORCE → APPLY`

## CTA

> Start with the Guided Edition.

## QA

- Do not describe Weekly Score as a forecast or signal.
- Do not imply audiobook listening progress is currently used for account recommendations.
- Do not show private progress rows or quiz answers.

# HOW-006 — Use Quizzes to Get Ahead

## Goal

Explain that quizzes are part of the learning path, not just end-of-course tests.

## Verified quiz behavior

- quiz submissions can return a next-quiz URL when a quiz is passed;
- quiz submissions can return a completion URL where applicable;
- learning progress is persisted through the governed quiz-progress system;
- quiz access and progression are entitlement-aware;
- users should use quizzes to check understanding before moving forward.

## Target duration

40–50 seconds.

## Narration

> The quizzes in USD Impact are not just tests at the end. Use them as checkpoints while you learn. Read or watch the lesson, open its quiz, and answer from the framework rather than from memory alone. When you pass an eligible quiz, USD Impact can move you to the next quiz or the next completion step. Your learning progress is retained, so you can stop and continue later. If you miss a question, use it to identify the concept worth reviewing before moving on. The goal is not a perfect score. The goal is to make the framework usable.

## Scene map

1. Opener: `USE QUIZZES TO GET AHEAD`
2. Lesson → Quiz
3. Answer choices / submit interaction
4. Passed state → `NEXT QUIZ`
5. Progress retained / continue later
6. Missed question → review concept
7. End frame: `TEST → REVIEW → CONTINUE`

## CTA

> Open the next quiz from your learning path.

## QA

- Do not promise that every quiz always exposes a next-quiz URL.
- Do not imply quiz performance is investment performance.
- Use generic demo answers; never expose a real member's answers.

# HOW-007 — Your 10-Minute USD Impact Routine

## Goal

Give members a simple recurring workflow that connects current research and structured learning.

## Target duration

45–55 seconds.

## Narration

> You do not need an hour every day to use USD Impact. Try a ten-minute routine. First, spend about two minutes on Daily USD Impact to see what is actually verified. Next, check the three dials: the dollar, real rates and liquidity. Then spend two minutes on Weekly Score or the Weekly Checklist to understand the broader regime. Use three minutes on one Guided Edition lesson, one audiobook section or one Video Library film. Finish with one minute on a quiz or a review question. The exact timing is flexible. The important part is the order: current evidence, regime context, deeper learning, then a quick test of understanding.

## Scene map

1. Opener: `YOUR 10-MINUTE USD IMPACT ROUTINE`
2. `2 MIN — DAILY USD IMPACT`
3. `2 MIN — THREE DIALS`
4. `2 MIN — WEEKLY SCORE / CHECKLIST`
5. `3 MIN — LEARN ONE THING`
6. `1 MIN — QUIZ / REVIEW`
7. Timeline collapses to `EVIDENCE → CONTEXT → LEARN → TEST`
8. End frame: `10 MINUTES. ONE REPEATABLE PROCESS.`

## CTA

> Save this routine and use it on your next visit.

## QA

- Timing is a suggested learning routine, not a claim that every user needs exactly ten minutes.
- Weekly Score must remain educational and non-predictive.
- No trading instruction or asset recommendation.
